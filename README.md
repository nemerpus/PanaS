# PanaS

PanaS es una aplicación para rutas en moto y grupos de riders: organización de salidas, telemetría y experiencias de ruta compartidas.

## Descargar

La aplicación se distribuye como APK firmado desde la página de [releases](https://github.com/nemerpus/PanaS/releases). Descarga la versión más reciente compatible con Android desde ahí.

## Código fuente

Este repositorio es el escaparate público y de descargas. No contiene código fuente.
